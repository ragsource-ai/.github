# RAGSource

**RAGSource** liefert belegte Rechtsquellen für KI-Systeme: Gesetze, Satzungen und Vorschriften mit Fundstelle, Stand und Link zum Original, für Verwaltung, Kommunen und Organisationen mit komplexen Regelwerken.

Das Angebot wird als gehosteter Dienst betrieben. Zugang und Konditionen über die jeweilige Marke:

| Marke | Website | Schwerpunkt |
|-------|---------|-------------|
| **amtsschimmel.ai** | [amtsschimmel.ai](https://amtsschimmel.ai) | Kommunale Verwaltung |
| **brandmeister.ai** | [brandmeister.ai](https://brandmeister.ai) | Feuerwehr und Gefahrenabwehr |
| **paragrafenreiter.ai** | [paragrafenreiter.ai](https://paragrafenreiter.ai) | Rechtsanwendung allgemein (in Vorbereitung) |
